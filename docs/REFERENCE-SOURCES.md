## Access and evidence ledger

Access date for this investigation: **2026-11-03**. Source URLs below were actually requested; successful HTTP retrieval is evidence of availability, not authenticated functional verification. Public help was retrieved through HTTPS using the configured proxy, parsed locally as text, then inspected by topic. Web-reader tools independently opened the landing pages/categories, permissions, advanced settings, pricing, tutorials and font/technical sources. No proprietary application JavaScript was analyzed or reused.

- Help: 14 top-level category pages + 108 article pages linked from those categories, then six further guest pages (114 article/navigation URLs total); all returned HTTP 200. H109 is a navigation-only guest page, not a behavioral specification.
- Marketing homepage and pricing: HTTP 200. Marketing is supplementary; specialist help and release notes anchor behavioral requirements. Source titles below are English descriptions of Persian originals.
- Office: web reader initially returned only a loading message. A separate Playwright run using system Chromium 155 loaded `https://office.mizito.ir/#/lg/login`, showing mobile/password inputs, login, forgotten-password and registration links. This is **O: login surface only**. No login, registration, OTP submission, trial activation or authenticated feature action was performed.
- Tutorial landing pages H013–H019: text and official links inspected. The short link `https://l.mizito.ir/mizito-tutorials-videos` failed in the web reader with a non-retryable 500/redirect retrieval error; target category C05 itself was accessible. Linked Aparat channel returned a JavaScript-required shell. **No video playback or recording content was verified.** No network restriction was bypassed.
- Release labels H020–H024 are the five entries in the public update index. No newer entry was linked there at access time; this does not establish the installed office/server build.
- No paid/authenticated advanced screens were available in this session. Use the focused owner checklist in OPEN-QUESTIONS.md. Do not request or commit passwords.

D = documentation; O = direct UI observation; I = inference; U = unknown. Public help often embeds desktop and mobile variants; native-only instructions are excluded from the web scope.
