# Miz-e Kar (میزکار)

Independent, Persian-first web collaboration software planned for self-hosting on Debian. The target is comprehensive functional and behavioral parity with Mizito's **web** application, including advanced features, with independent branding and assets.

**Current status: Phase 0 discovery and planning only. No application, scaffold, dependencies, or deployment has been created. No feature parity is claimed.**
